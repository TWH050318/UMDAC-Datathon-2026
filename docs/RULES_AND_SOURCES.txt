RECONSTRUCTED RULES, WITH CHART AND CODE SOURCES
==================================================================
Instructions / How to read this file
- Each rule represents a relational statement that can be added directly to a dashboard (phrased in English for easy copy-pasting).
- STATUS: PROVEN = Valid across 100% of the dataset; SUPPORTED = Backed by quantitative evidence with alternative explanations ruled out;
OPEN = A pattern has been observed, but the underlying mechanism remains undetermined; REJECTED = Proven invalid upon testing (must still be reported).
- CHART = A visualization located in `outputs/charts/`; TABLE = An aggregated dataset in `outputs/csv/` (suitable as a data source for Power BI);
CODE = A specific notebook and section heading within the `notebooks/` directory. "(no chart)" indicates that only a table is available.
- All figures are calculated based on the full dataset of 10,000,000 rows, unless a specific scope is otherwise stated.
- The suggested dashboard page is indicated in the group heading.

[R1] PARTICIPANT_COUNT equals the number of BICs listed in BIC8_PATH ("..." not counted).
     Size/scope: 10,000,000 of 10,000,000 rows.            STATUS: PROVEN

[R2] TRANSACTION_TYPE_CODE is "Direct" if and only if the path has exactly 2 banks.
     Size/scope: all rows, 0 exceptions.                    STATUS: PROVEN
     CHART: (no chart)   TABLE: (shown in notebook)
     CODE: 01_routing_duration_fx.ipynb, H-A1

[R3] Path length is geometric: each additional bank keeps 36.8% of the payments
     (ratio 0.363-0.372 for 2 to 9 banks), in every customer flow and for domestic
     and cross-border payments alike. 0.368 is close to 1/e; we cannot confirm that
     this is the intended parameter.                        STATUS: SUPPORTED
     CHART: A2_participant_count_geometric.png   TABLE: routing_participant_count.csv
     CODE: 01_routing_duration_fx.ipynb, H-A2

[R4] With 3 or more banks, a payment is "Covered" with a fixed probability that does
     not depend on path length or amount: 20% if domestic, 10.6% if cross-border
     (otherwise "Indirect").                                STATUS: SUPPORTED
     CHART: E10_covered_share.png   TABLE: routing_covered_by_k_domestic.csv, routing_covered_share.csv
     CODE: 05_completion.ipynb, section E; 01_routing_duration_fx.ipynb, H-A3

[R7] Each end of the path is replaced by a random bank in 5% of payments,
     independently (first 4.98%, last 4.99%, both 0.247% vs 0.249% expected).
     ORDERING_BIC8 / BENEFICIARY_BIC8 keep the customer's real bank: in these rows the
     IBAN country and bank code still match the BIC column in 100% of cases, while the
     path's end bank is in the same country only 4.8% of the time. Amount, duration and
     routing are unchanged. Labelled anomalies are about half as frequent in these rows
     (3.9 vs 7.3 per 10,000) - not explained.               STATUS: SUPPORTED (meaning OPEN)
     CHART: (no chart)   TABLE: endpoint_mismatch.csv
     CODE: 05_completion.ipynb, section C; 01_routing_duration_fx.ipynb, H-A4

[R5] CONTINUITY_QFLAG = "N" if and only if BIC8_PATH contains "...".

[R6] Each link of a path is hidden independently with probability 5%, so the share of
     discontinuous paths is 1 - 0.95^(k-1) for k banks (observed 5.0%, 9.7%, 14.2%,

[D1] Duration is decided by the banks on the path, not by the payment. For direct
     payments the pair of banks explains 98.4% of the variance of log10(duration)
     (32,734 bank pairs with 30+ payments). Customer type, weekend, hour and amount
     add almost nothing.                                    STATUS: SUPPORTED
     CHART: B2_duration_direct_bimodal.png   TABLE: duration_variance_explained.csv
     CODE: 04_open_questions.ipynb, section 1 (H1); 01_routing_duration_fx.ipynb, H-B2

[D2] Each bank has its own processing delay and delays add up along the path: delays
     fitted on 2-bank payments predict 3-bank Indirect payments with correlation 0.93
     (log scale); median duration rises 39 s -> 126 -> 418 -> 590 -> 796 s for 2..6 banks.
     Estimates for fast banks are imprecise; Covered payments fit less well (0.83).
                                                            STATUS: SUPPORTED (fast banks / Covered OPEN)
     CHART: D1_duration_additive_validation.png, B2_duration_by_participants.png
     TABLE: duration_additive_validation.csv, duration_by_participants.csv
     CODE: 04_open_questions.ipynb, section 1 (H2); 01_routing_duration_fx.ipynb, H-B2

[D3] Large banks are fast: among banks with 300+ direct payments, only 0.5% of the
     largest eighth are slow (delay over 150 s) against 50-55% in every other size group.
                                                            STATUS: SUPPORTED
     CHART: D1_bank_delay_distribution.png   TABLE: bank_delay_by_size.csv
     CODE: 04_open_questions.ipynb, section 1 (H3)
